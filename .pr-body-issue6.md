## Problem
Home page has no content — only layout shell from #5. Issue #6 requires composing the first two sections (hero + trust bar) with proper placeholder slots for the remaining seven.

## Approach
Built two new section components and composed `src/app/page.tsx`:

### Hero (`src/components/sections/Hero.tsx`)
- Full-bleed navy scrim over a geometric grid pattern — evokes engineering/blueprint without fake "real" imagery
- Eyebrow with blue-line leading rule, Archivo H1 value prop, Inter subtitle
- Dual CTAs: signal-orange "Get a Free Quote" link + phone number with icon
- Trust strip below CTAs (licensed & insured / East Coast coverage / door-to-door)
- Gradient fade at bottom into next section for visual continuity
- Placeholder marked `TODO(owner-content)` — no fake imagery

### TrustBar (`src/components/sections/TrustBar.tsx`)
- Dark navy band using the existing `Stat` primitive from UI layer
- Renders only owner-confirmed stats; hidden entirely when none confirmed (never fakes)
- Grid layout: 2 cols mobile → 3 cols tablet+

### Page composition (`src/app/page.tsx`)
- Hero → TrustBar → 7 typed placeholder slots in approved order
- Alternating foam/mist backgrounds on placeholders per DESIGN_SYSTEM §4 rhythm
- No business logic in page — pure section composition

## Acceptance Criteria
- [x] Home renders at mobile/tablet/desktop with correct section rhythm and alternating foam/mist backgrounds — no layout breakage
- [x] Primary CTA reachable without scrolling on desktop; via sticky call bar on mobile
- [x] TrustBar degrades gracefully when no stats are confirmed (hidden, never fake)
- [x] Keyboard + focus pass clean; single H1 on the page
- [x] Visual consistency: tokens only, accent ≤ 2 places per viewport (signal used once for CTA), hero scrim keeps text contrast ≥ 4.5:1

## Validation
- `next build` passes clean (TypeScript + static generation)
- Hero uses navy scrim gradient ensuring ≥ 4.5:1 contrast regardless of future image
- TrustBar hidden when CONFIRMED_STATS is empty — zero fake data risk
- RSC by default; no client components needed for this shell
